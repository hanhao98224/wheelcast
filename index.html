Is the published record the one that is running?

checking

The documentation publishes one set of addresses; the live API, the website and the settlement pipeline use another. Both are read at runtime and compared field by field. Wheelcast follows the live deployment, because that is where the rounds are.

published ABI vs live logs

Every event signature in the published ABI is hashed to its topic and matched against the topics the live contract actually emits. An ABI that matches nothing on chain describes a different contract, however correct it looks on its own.
